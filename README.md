# 汉字 · 笔顺 · 拼音

给家长用的简易汉字显示网页小工具：输入汉字，满屏正楷显示，带拼音，点一下就能按笔顺逐笔演示。

**完全离线。** 双击 HTML 文件即可使用，不需要联网，也不会上传任何内容。

![演示](web-demo.gif)

## 功能

- 满屏正楷显示，矢量字形，放多大都不模糊
- **每个字上方显示带声调的拼音**：多字时按词组判断多音字（如「银行」显示 yín háng），单字显示最常用的读音
- 点击某个字，按笔顺逐笔播放；还没画到的笔画保持浅灰，看得见整体结构
- 一次最多显示 3 个字
- 收录 9574 个简繁汉字，含常用字与大部分生僻字
- 支持全屏，适合投到电视或平板上给孩子看

## 用法

到 [Releases](../../releases) 页面下载 `大字.html`，双击用浏览器打开，然后在底部输入框打字即可。
字会自动放大显示，每个字框上方带拼音，默认不自动播放；鼠标点某个字的框，才会播放这个字的笔顺。

未收录的字会提示「未收录」。

想自己从源码生成，把仓库拉下来后运行 `python3 build.py`，会在根目录得到同样内容的 `大字.html`。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `大字.html` | 单文件版：库和全部字库都内联，可单独拷走（约 30 MB）。构建产物，不入库，随 Release 发布 |
| `index.html` | 开发版：引用同目录下的 JS 文件，改代码时用这个 |
| `hanzi-data.js` | 字库（9574 字，约 29 MB） |
| `hanzi-writer.min.js` | Hanzi Writer 3.7.3，负责笔顺动画 |
| `pinyin-pro.min.js` | pinyin-pro 3.29.5，负责拼音与多音字判断 |
| `build.py` | 运行 `python3 build.py` 重新生成单文件版 |
| `ARPHICPL.TXT` | 笔画数据所用的 Arphic Public License 全文 |
| `pinyin-pro-LICENSE.txt` | pinyin-pro 的 MIT 许可证 |
| `web-demo.gif` | README 里的演示动图 |
