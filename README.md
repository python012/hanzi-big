# 汉字 · 笔顺 · 拼音

给家长用的简易汉字显示网页小工具：输入汉字，满屏正楷显示，带拼音，点一下就能按笔顺逐笔演示。

**完全离线。** 双击 HTML 文件即可使用，不需要联网，也不会上传任何内容。

**下载：** 到 [Releases](../../releases) 页面下载 `hanzi-big.html`，保存到本地，双击用浏览器打开即可。

![演示](web-demo.gif)

## 功能

- 满屏正楷显示，矢量字形，放多大都不模糊
- **每个字上方显示带声调的拼音**：多字时按词组判断多音字（如「银行」显示 yín háng），单字显示最常用的读音
- 点击某个字，按笔顺逐笔播放；还没画到的笔画保持浅灰，能看到整体结构
- 一次最多显示 3 个字
- 收录 9574 个简繁汉字，含常用字与大部分生僻字
- 支持全屏，适合在电脑上使用，也可以投到电视或平板上给孩子看

## 用法

打开下载的 HTML 文件后，在底部输入框打字即可。
字会自动放大显示，每个字框上方带拼音，默认不自动播放；点击某个字的框，才会播放这个字的笔顺。

未收录的字会提示「未收录」。

仓库里不含单文件版（构建产物，随 Release 发布）。想自己生成，把仓库拉下来运行 `python3 build.py`，会在根目录得到 `hanzi-big.html`，内容和发布附件相同。
